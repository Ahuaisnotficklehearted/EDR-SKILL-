## 5. 三源工况矛盾（务必注意）

数据表(Rev A)、HTRI xls、原 EDR 三源的温度/压力/流量**不一致**：
- 数据表：冷侧 150→155℃ / 560 kPaG；热侧 250→150℃ / 1200 kPaG
- HTRI：冷侧 139→142.58℃ / 450 kPa；热侧 175℃冷凝 / 900 kPa
- 原 EDR：冷侧 150→155℃ / 340 kPa；热侧 250→150℃ / 900 kPa

**教训**：建模前必须让用户/设计院指定唯一权威工况。本案例以"冷侧 150→155℃、蒸发率 12%"为硬指标（用户确认），压力以原 EDR 为准。

## 6. 关键坑与经验

1. **BEX 物性链接损坏** → 原 EDR 变空壳（事故全记录见 04_过程记录/事故报告）。**恢复原件后验证确认：物性全依赖失效 BEX，FileOpen 静默清空 BEX，Run 报 1250。真正要重建的是"物性底座"，不是几何。**
2. **物性方法不一致**：原 EDR 冷侧 PENG-ROB，但 Aspen Plus 底座是 ELECNRTL（酯化电解质）。含醋酸/水的酯化体系应统一 ELECNRTL。
3. **再沸器冷侧蒸发、热侧冷凝**的相态设定要正确（VapFrcIn/Out、VaporizerType=4 降膜）。
4. **降膜再沸器**：管侧液体沿管壁降膜蒸发，适合热敏物料、低压降；管侧压降严控（≤10 kPa）。
5. **锆材**：醋酸在高温下腐蚀性强，需 Zr 或高合金，材料选择要匹配介质。

## 6.1 物性重建路径（复现确认后的下一步）

原 EDR 物性全依赖失效 BEX，重建三步：
1. **Aspen Plus 底座**：`Simulation 5-ok-1-4.apwz`（ELECNRTL 酯化体系，组分=水/正丁醇/乙酸丁酯/醋酸/乙酸异丁酯/甲磺酸+离子），确认 0 error/warning 后提取冷侧组成+物性曲线。
2. **重新导入 EDR**：二选一——
   a. 链接法：Aspen Plus HeatX 生成 BEX → `BJACApp.ImportPFS(EDRfile, BlockName, AppName, AspenApp)`（V15 已注册 SimInterface.APlus2Tasc，待实测）；
   b. 固化法：把组分（AspenDBComposition/NameOfComponents 等数组）+ 物性曲线（LiquidDensity/Viscosity/... 数组）直接写进 XML，`AspenPropertySelection=0`。
3. **校验收敛**：Run 后 rc==0 + ErrorDescription=='Normal operation'，对照 HTRI 基准（U=783.58、Q=14.394 MW）验收。

## 7. 复用要点（做同类再沸器的模板）

- 酯化/酯化再沸器 → ELECNRTL + 组分（水/醇/酸/酯/催化剂）
- 立式降膜 → Tasc + VaporizerType=4 + ExchPosi=2 + BEM
- 硬指标先锁定：蒸发率、进出口温度、允许压降
