# EDR 换热器设计标准工作流（端到端 SOP）

> 从"一堆输入材料"到"带尺寸的成熟换热器"的完整可复现流程。每步产出放版本文件夹对应子目录。
> 对应目录约定：`01_校核后的输入材料/` `02_AspenPlus物性/` `03_EDR模型/` `04_过程记录/` + 顶层 `说明文档.md`。

## 阶段 0：输入拆解与归档（用户要求第 1 条）

1. 识别输入类型：文本 / 图片（图纸）/ 表格（xls/xlsx）/ PDF（数据表、说明书）。
2. 拆分提取：
   - PDF → pymupdf(fitz) 提文本 + 渲染页面为 PNG 人工/多模态复核（数据表、管口表、设备图）。
   - xls/xlsx → xlrd/openpyxl 逐 sheet（HTRI Xist 的 Output Summary/Final Results 结构固定）。
   - .EDR → `edr_xml.py` 离线解析。
   - 图片/图纸 → 转 PNG 逐项读图（管口表、管子规格、装配尺寸、TEMA 类型）。
3. **多源交叉校核**：把同一参数从所有来源汇总成《输入校核与差异表》，不一致处显式标注。
   - E-6101 教训：数据表(Rev A)、HTRI xls、原 EDR 三源温度/压力/流量全部不一致 → 必须让用户指定唯一权威基准。
4. 校核后材料归档到 `01_校核后的输入材料/`，提取脚本一并留档。

## 阶段 1：Aspen Plus 物性底座（用户要求第 2、4 条）

1. 用 aspen-plus-automation skill 打开/重建 Aspen Plus 模型（或直接用用户提供的 .apwz/.bkp）。
2. 确认模型 **0 error / 0 warning**（`.his` 0/0/0），否则先修模型。
3. 提取到 `02_AspenPlus物性/`：
   - 冷/热侧组成（组分 + 摩尔/质量分数）
   - 物性方法（ELECNRTL/PENG-ROB/NRTL...）+ 游离水方法
   - 关键物性曲线（密度/粘度/比热/导热系数/汽化焓 vs 温度压力）
   - 冷/热侧流量、进出口温压、相态、蒸发/冷凝率
4. **铁律：EDR 侧物性方法必须与此处一致**。

## 阶段 2：EDR 建模与热力设计（用户要求第 3 条）

1. 选型（见 industry-standards-and-rules.md §2）→ 定程序名 Tasc/Acol/Aple/...
2. 建模型两条路：
   - **模板法**：复制同类型官方示例为副本，替换标量/数组（推荐，结构已验证）。
   - **链接法**：Aspen Plus HeatX 生成 BEX → `BJACApp.ImportPFS(EDRfile, BlockName, AppName, AspenApp)`（需实测）。
3. 输入：几何（壳径/管径/管长/管数/折流板）、工艺（流量/温压/相态/污垢/允许压降）、物性（方法+数据）。
4. 运行：`Run(程序名)`，判定 rc==0 且 ErrorDescription=='Normal operation'。
5. 校验结果：热负荷、面积、U 值、两侧压降、面积余量是否达标；不达标调几何重跑。
6. 输出到 `03_EDR模型/`：带尺寸的 .EDR + 结果摘要（关键结果标量导出）。

## 阶段 3：Mechanical 设计（用户要求第 4 条，可选）

1. 热力设计完成后**明确询问用户**是否需机械设计（TEMA/ASME/GB 强度、壁厚、法兰、管板、膨胀节）。
2. 需要则走 Shell&Tube Mechanical 流程：设计压力/温度 → 材料 → 壁厚 → 管板 → 法兰 → 振动校核。
3. 产出：机械设计数据表、材料清单、图纸级参数。

## 阶段 4：输出与文档（用户要求第 5、6、7 条）

1. **版本化文件夹**：`<项目>_v<N>/`，改动时复制旧版到 `_v<N+1>/` 再改，**永不修改旧版**；文件夹名只用字母数字下划线连字符（无空格、无中文、无特殊字符）。
2. **每次输出成果 = 一个版本文件夹**（硬性要求），内含三类文件，**全部带版本号命名**：
   - **Aspen Plus 模型**：`.apwz` 或 `.bkp`（如 `E6102_AspenPlus物性底座_v2.apwz`），供用户自行编辑修改；
   - **EDR 文件**：`.EDR`（如 `E6102_EDR模板参考_v2.EDR`），供用户在 EDR 里自行打开修改；
   - **说明文档.md**（如 `说明文档.md`，内含版本号与溯源）。
   - **源文件不动**：修改时先复制源文件重命名为 `*_v<N>.*`，再在新文件上改，旧版/原版一律不动。
3. **说明文档.md**（每次必出，顺序固定）：
   1. 工艺说明（这是什么换热器、做什么、关键指标）—— 置顶
   2. 基础信息（位号、类型、材料、设计条件）
   3. 本文件夹交付物清单（版本化命名对照表）
   4. 过程记录（输入校核结论、建模步骤、运行结果、遇到的问题与解决）
   5. 当前状态与续做路径（未完成项 + 下一步）
   6. 溯源（每个输入来自哪个源文件、哪个 Aspen Plus 模型）
4. **Token 控制**（用户要求第 5 条）：每完成一个阶段主动保存（FileSaveAs + 更新说明文档），不等到全流程结束才存；中断可续。

## 阶段 5：验收对照

- 与权威基准对照（如 HTRI 报告的 U/Q/余量），偏差需解释。
- 检查是否满足工艺硬指标：E-6101 冷侧 150→155℃、蒸发率 12%、压降 ≤10 kPa。
