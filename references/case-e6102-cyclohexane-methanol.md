# 案例：E-6102 环己烷-甲醇冷凝蒸发器（从零设计）

> 本 skill 的第二个案例：**纯组分体系、从零设计**（区别于 E-6101 的混合酯化体系、评级恢复）。验证"无需 Aspen Plus BEX 链接、直接用 EDR 内置库"的路径。

## 1. 工艺条件（用户给定，已做热力学自洽校核）

| 参数 | 热侧 环己烷 | 冷侧 甲醇 |
|---|---|---|
| 流量 | 5.4 kg/s | 2.0 kg/s |
| 入口 T/P | 172 ℃ / 8.0 bar(a) | 80 ℃ / 5.0 bar(a) |
| 入口气相分数 | 1.0 饱和蒸汽 | 0.0 过冷液 |
| 出口 T/P | 170.8 ℃ / 7.8 bar(a) | 109.5 ℃ / 4.7 bar(a) |
| 出口气相分数 | 0.0 饱和液 | 0.70 两相 |
| 相变 | 冷凝率 100% | 蒸发率 70% |
| 热负荷 | -1.53 MW | +1.53 MW |

## 2. 热力学自洽性（关键校核结论）

- **冷侧自洽**：甲醇蒸发 70% 潜热 = 2.0 × 0.70 × 1100 kJ/kg = **1.54 MW** ✓
- **热侧需注意**：环己烷 8 bar（接近临界 40.8 bar 的 0.2 倍）汽化热**显著低于**常压 380 kJ/kg，约 283 kJ/kg 时 5.4 kg/s 全冷凝 = 1.53 MW ✓。手算用常压汽化热会高估（2.05 MW）。
- **教训**：高压下汽化热随压力降低，接近临界时趋零，手算必须用操作压力下的值（EDR 内置库/Aspen 精确值）。

## 3. 类型与结构判断

- 热侧冷凝 + 冷侧沸腾 → 管壳式冷凝蒸发器
- EDR 程序 **Tasc**；建议立式 **BEM**，热侧环己烷蒸汽走**壳程**冷凝、冷侧甲醇走**管程**沸腾
- 参考模板：`TS-Condenser-Vertical_BEM.EDR`（冷凝）/ `ForcedVaporizer_BEM.EDR`（蒸发）

## 4. 与 E-6101 的本质区别（决定建模路径）

| 维度 | E-6101（酯化再沸器） | E-6102（环己烷-甲醇） |
|---|---|---|
| 体系 | 多组分酯化混合物（水/醇/酸/酯+离子） | 两侧纯组分 |
| 物性方法 | ELECNRTL（电解质） | 环己烷 PENG-ROB、甲醇 NRTL/NRTL-RK |
| 物性来源 | 必须 Aspen Plus BEX 链接 | **EDR 内置 B-Jac 库直接有** |
| 建模风险 | BEX 链接断 = 物性全失（已发生） | 无 BEX 依赖，更稳 |

**结论**：纯组分体系优先用 EDR 内置库（`DBToBeUsed=4` 即 B-Jac），设组分符号 + 物性方法，让 EDR 自生物性曲线，**规避 BEX 断链风险**。

## 5. 手算初筛结果

- LMTD ≈ 76 ℃（dT1=62.5，dT2=90.8）
- 经验 U（有机蒸汽冷凝-有机液沸腾）300~800 W/m²·K
- 面积量级 **25~67 m²**（中等规模）

## 6. 建模要点（从零建纯组分 EDR）

1. 复制官方模板（TS-Condenser-Vertical_BEM 或 ForcedVaporizer_BEM）为工作副本。
2. 通过 COM 设置（待完善：B-Jac 组分注入的精确 API）：
   - 冷侧组分 = METHANOL，物性方法 NRTL/NRTL-RK，DBToBeUsed=4（B-Jac 库）
   - 热侧组分 = CYCLOHEXANE，物性方法 PENG-ROB，DBToBeUsed=4
   - 或 `ImportPFS`（从 Aspen Plus PSF 导入，接口已确认存在，签名待实测）
3. 设工艺标量：FlRaCS/HS、TempIn/Out、PresOperIn/Out、VapFrcIn/Out、FoulRes、PrDrAllo。
4. 设几何初值：壳径/管径 φ25/管长 6m/布管 60°/折流板。
5. Run 校核：rc==0 + ErrorDescription=='Normal operation'；查 TascMsg 无 Operation Failure。
6. 对照手算量级（面积 25~67 m²）验收，偏差大则查物性/几何。
