# 换热器行业规定与设计规范（EDR 建模的"硬约束"库）

> 本文档是 Aspen EDR 自动化 skill 的行业知识底座。建模前先查这里，避免做出"物性对、但不符合工程规范"的废件。
> 分四部分：① 流股/命名规定 ② 换热器类型选型 ③ 设计参数经验值 ④ 规范依据（TEMA/GB/ASME）。

## 1. 流股与命名规定

### 1.1 位号命名（行业通用）
- 换热器位号通常 `E-XXXX`（Exchanger），再沸器/冷凝器/冷却器/加热器同属。
- 常用细分前缀：`E-` 换热器、`B-` 塔/容器、`P-` 泵、`C-` 压缩机、`F-` 加热炉。
- EDR 内 **FluidNamCS / FluidNamHS**（冷/热侧流体名）建议用位号+相态，如 `E6101-CS`、`E6101-HS`；示例文件常给 `S1`/`H1`，正式交付应改回可读名。

### 1.2 冷热侧约定（EDR 专用，务必分清）
- EDR 里 **CS = Cold Stream（冷侧/被加热）**，**HS = Hot Stream（热侧/被冷却）**。
- 再沸器：**冷侧 = 管侧 = 被加热蒸发的工艺物料**；热侧 = 壳侧 = 加热介质（蒸汽/导热油）。E-6101 正是此配置。
- 冷凝器：热侧 = 被冷凝的蒸汽（走壳侧），冷侧 = 冷却水（走管侧）。
- **易错点**：不要用"进出口温度高低"去猜哪侧冷热，要看谁吸热谁放热。再沸器冷侧出口温度反而更高（150→155℃ 升温），但仍是"冷侧"因为它吸热。

### 1.3 物性方法命名与一致性（Aspen Plus ↔ EDR 打通的关键）
| Aspen Plus 物性方法 | EDR 对应 `PropMethodHSSTR/CSSTR` | 适用体系 |
|---|---|---|
| ELECNRTL | ELECNRTL | 电解质、含醋酸/水/醇的酯化体系、吸收 |
| PENG-ROB / PR-BM | PENG-ROB | 烃类、非极性、高压 |
| NRTL / NRTL-RK | NRTL | 极性非电解质 |
| STEAM-TA | STEAM-TA | 水蒸气（游离水处理） |
| UNIQUAC | UNIQUAC | 醇水等 |
- **铁律：EDR 侧物性方法必须与 Aspen Plus 底座一致**，否则传热/压降全错。
- E-6101 教训：原 EDR 冷侧写 PENG-ROB，但 Aspen Plus 主模型是 ELECNRTL（酯化电解质体系），存在方法不一致，重建时必须统一为 ELECNRTL。

### 1.4 单位制
- 全流程统一 SI：温度 ℃、压力 kPa（或 bar）、流量 kg/h、热负荷 kW/MW、面积 m²、K 值 W/(m²·K)。
- EDR 内部 `uomset` 控制显示单位，导出结果时显式带单位，禁止混用 kPa/bar/MPa。

## 2. 换热器类型选型（EDR 程序名对照）

| 类型 | EDR 程序名 | 典型场景 |
|---|---|---|
| 管壳式 (Shell & Tube) | **Tasc** | 最通用；再沸器、冷凝器、冷却器 |
| 空冷器 (Air Cooled) | **Acol** | 无循环水、大热负荷放空 |
| 板式 (Plate) | **Aple** | 低粘度液-液、紧凑、易清洗 |
| 板翅式 (Plate Fin) | **PlateFin** | 深冷、气体 |
| 绕管式 (Coil Wound) | **CoilWound** | LNG 主换热器 |
| 加热炉 (Fired Heater) | **Fire** | 高温加热、辐射段 |
| 降膜蒸发器 | 仍走 **Tasc** + VaporizerType=4 | 立式降膜再沸器（E-6101） |

**选型要点**：
- 液-液/气-液、大温差、易结垢 → 管壳式。
- 纯液相低粘度、两侧都清洁 → 板式（换热效率高、占地小）。
- 热侧是蒸汽冷凝、冷侧蒸发 → 管壳式再沸器（釜式/立式热虹吸/降膜）。
- 无冷却水、需空气冷却 → 空冷器。

## 3. 设计参数经验值（缺省时可先取，再让用户确认）

### 3.1 流速与压降（行业惯例）
| 介质 | 管侧流速 | 允许压降 |
|---|---|---|
| 液体 | 0.5~3 m/s（常用 1~2） | 10~70 kPa |
| 气体/蒸汽 | 10~30 m/s | 5~20 kPa |
| 冷却水 | 1~2.5 m/s | 50~100 kPa |
| 高粘液体 | 0.2~1 m/s | 视情况 |
- **再沸器/蒸发器管侧压降要严控**（影响沸点与循环），E-6101 允许压降仅 10 kPa。
- 气相入口要有防冲挡板，流速过高会振动（振动校核见 TEMA）。

### 3.2 污垢热阻 Fouling（m²·K/W，EDR 的 FoulResCS/HS）
| 流体 | 污垢热阻 |
|---|---|
| 冷却水（处理后） | 0.00018~0.00035 |
| 干净有机液 | 0.00017~0.00026 |
| 含醋酸/腐蚀性 | 0.0003~0.0005 |
| 水蒸气（干净） | 0.00009~0.00017 |
| 导热油 | 0.0002~0.0005 |
- E-6101：冷侧（酯化物料，含醋酸）0.0003、热侧（蒸汽）0.0002 —— 取值合理。

### 3.3 换热器设计余量（Overdesign）
- 常规工况设计余量 **30%~50%**（面积余量）。
- 再沸器/冷凝器因波动大，余量常取 30%~50%。
- E-6101 的 HTRI 基准余量 93.33% 属于**异常偏高**（可能是 Rating 模式下"现有设备核验"而非新设计），新设计不应照抄此余量。

### 3.4 换热系数 K 值参考（W/(m²·K)）
| 工况 | 大致 U |
|---|---|
| 水-水 | 1000~2500 |
| 蒸汽冷凝-水 | 1000~3000 |
| 有机蒸气冷凝-水 | 300~800 |
| 沸腾-蒸汽 | 500~1500 |
| E-6101（酯化再沸，Zr 管） | HTRI 实测 783（含污垢） |

### 3.5 几何经验值
- 管长标准：3 / 4.5 / 6 / 7.5 / 9 m（首选 6 m）。
- 管径：常用 φ19 / φ25 / φ32（再沸器蒸发用 φ25/φ32）。
- 管间距（节距比）：1.25（最常用）/ 1.33。
- 布管角：30°（最紧凑）/ 45° / 60°（压降最小）/ 90°。
- 折流板：单弓形、切口 15%~45%（常用 25%）、间距 0.2~1.0 倍壳径。
- 壳径：标准系列，向上取整到标准值。

## 4. 规范依据（引用而非照抄，作为合规检查清单）

### 4.1 TEMA（管壳式换热器制造商协会标准）
- TEMA 分类：BEM（前端固定管板+后端固定）、BEU（U 形管）、AEL、NEN 等。
- E-6101 为 **BEM**：立式、固定管板、单程。
- 检查项：管板厚度、法兰等级、折流板与管支撑、管束抽出空间、膨胀节是否需（温差 >50℃ 且无 U 形管 → 需膨胀节，EDR 的 ExpJointReq）。

### 4.2 GB/T 151（中国管壳式换热器）
- 国内设计院常用，管壳式换热器设计、制造、验收。
- 与 TEMA 对应，国内项目用 GB/T 151，涉外项目用 TEMA/ASME。

### 4.3 ASME 第 VIII 卷（压力容器）
- 换热器外壳按压力容器校核壁厚，设计压力/温度决定材料与壁厚。
- E-6101 设计压力 CS 800 kPa / 285℃、HS 1000 kPa / 285℃。

### 4.4 振动校核
- 壳侧流体横掠管束可能诱发振动（卡门涡街/流体弹性不稳定/声共振）。
- EDR 会输出振动分析结果；若超限需调折流板间距/加支撑。

## 5. 建模前自检清单（每次都要过一遍）

- [ ] 冷/热侧是否分清（再沸器冷侧=管侧蒸发物料）
- [ ] 物性方法是否与 Aspen Plus 底座一致
- [ ] 冷侧蒸发率/冷凝率目标是否正确（E-6101：冷侧出口蒸发率 12%）
- [ ] 进出口温度/压力是否取自权威工况表（多源一致）
- [ ] 污垢热阻是否按介质合理取值
- [ ] 允许压降是否合理（再沸器管侧 ≤10 kPa）
- [ ] 换热器类型选型是否正确
- [ ] 材料是否匹配介质腐蚀性（E-6101 用 Zr-3 锆，因醋酸腐蚀）
- [ ] 设计余量是否在合理区间（30~50%）
