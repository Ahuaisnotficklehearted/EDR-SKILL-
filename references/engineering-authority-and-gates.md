# 换热器设计的工程方法论与权威边界

> 本文档是本 skill 的工程方法论速览，核心思想：**分清"谁有权决定什么"，手算/手册/教材/EDR 各归其位，绝不混用。** 完整的三权威治理、状态机、8 步工作流、验收门、停止/迁移规则见 `edr-rating-methodology.md`。

## 1. 三个权威分离（Three Authorities，本 skill 的核心治理原则）

做一台换热器，必须始终分清三个"权威"来源，各管各的，不越界：

| 权威 | 决定什么 | 来源 |
|---|---|---|
| **工艺权威 Process** | 冷热侧组成、流量、进出口温压、相态、热负荷、蒸发/冷凝率、压降约束 | 认可的 Aspen 案例 / 设计院条件表 |
| **EDR 权威 EDR** | 几何尺寸、面积、U、压降、流速/RhoV2、振动、物性范围 | 同设备 .EDR 真实运行结果 |
| **交付权威 Delivery** | Required Input 完整、零警告零错误、工艺目标不被动改 | 精确复开复算的最终文件 |

**铁律**：
- 不能用一次干净的 Aspen 运行掩盖 EDR 的工程失败；
- 不能用一份干净的 EDR 报告绕过 Aspen 交付门；
- 手算面积只作初筛，最终面积/压降/振动必须 EDR。

## 2. 参数权威等级（哪些值能信、哪些只作 sanity check）

| 参数 | 权威来源 | 边界 |
|---|---|---|
| 热负荷 Q | 工艺权威（Aspen/条件表） | 教材只给能量衡算方法，不给数值 |
| LMTD | 数学公式可用 | 复杂多程/相变正式值用 EDR |
| 总传热系数 U | **只能 EDR** | 手册经验 U 只作 sanity check |
| 污垢热阻 | 手册查取方法 | 不能自动改项目默认值 |
| 换热面积 A | **只能 EDR** | 手算只作初筛 |
| 管/壳程流速 | 手册经验范围 | 只作 sanity check |
| 允许压降 | 项目压降分配 | 手册不替代，需工艺包 |
| 管板/折流板/法兰 | 固定管板手册作结构入口 | 正式需 EDR/SW6/厂家 |

**核心判断（化工原理 CH04）**：总传热系数不是脱离物系、流型和设备结构的通用常数；换热量闭合≠温度曲线无交叉、压降可接受、设备可操作。

## 3. EDR 评级的状态机与晋升阶梯

### 3.1 HeatX 分类状态机（判断"到底做没做真实 EDR"）

| 状态 | 含义 |
|---|---|
| `unverified` | 证据不足，无法确定 EDR 状态（缺项≠失败，未知门≠已失败） |
| `shortcut` | 仅流程级 shortcut 计算 |
| `detailed_non_edr` | Detailed 计算但**没走 EDR** |
| `edr_file_unaccepted` | .EDR 存在但消息/结果门失败 |
| `edr_unbound` | .EDR 通过但 Aspen 绑定丢失 |
| `edr_accepted` | EDR + 精确 Aspen 交付门全过 |

**反例识别**：`CALC-METHOD=DETAILED` 不是 EDR；`Run2=0` 不是 EDR 完成；干净 `.his` 不是 EDR 身份证据；有 .EDR 文件名不等于有有效结果。

### 3.2 晋升阶梯（不能跳级）

1. 文件存在（仅文件名，不声称已算）
2. EDR 计算通过（同设备文件 + 消息/结果有效）
3. Aspen 绑定通过（EDR 复开存活 + 输出填充）
4. Aspen 交付通过（精确复制文件过 Required Input + 零警告 + 工艺门）
5. 工程设计通过（面积/压降/振动/物性范围/材料闭合）
6. 机械/厂家通过（SW6/图纸/制造/性能保证）

**模型可能过第 4 级但面积余量/材料在第 5 级仍开放——不能塌缩这些级别。**

## 4. 工程验收门（Engineering Acceptance Gates）

| 检查项 | 通过证据 | 常见失败 |
|---|---|---|
| 热负荷 | EDR duty 匹配冻结工艺目标 | EDR 静默改了工艺 duty |
| 面积 | 需要/实际面积都报告，余量可接受 | 负面积余量 |
| U/热阻 | 值填充且物理合理 | shortcut/默认 U 冒充 EDR |
| 压降 | 壳/管压降在允许内 | 真空侧/循环扰动 |
| 流速/RhoV2 | 无高 RhoV2 指示 | 进口/横流负荷过大 |
| 振动 | 无未解决振动警告 | 无支撑管/不良壳排列 |
| 物性范围 | 曲线覆盖全 T/P 包络 | APPDF 温度/压力越限 |
| 材料 | 温度/腐蚀/制造依据记录 | 从别的换热器照抄合金 |
| 工艺整合 | 相态/循环/产品/能力保持 | 干净 EDR 破坏下游 Aspen |

## 5. 失败特征与决策（Failure Signatures）

| 特征 | 决策 |
|---|---|
| `DETAILED` 但无 EDR 输出 | 非 EDR |
| `TascMsg` 有 `Operation Failure` | 隔离 |
| 物性曲线低于操作温度 | 重新生成/扩展物性 |
| EDR 路径丢失或复开后模式重置 | 绑定失败 |
| 负面积余量 | EDR 存在，工程动作开放 |
| 振动靠并联解决 | 重评级 + 重跑全部 Aspen 门 |
| EDR 改了受保护 duty/循环/产品 | 拒绝或取得授权 |

## 6. 停止规则（Stop Rules，宁可隔离不可硬做）

出现以下任一，**停止并隔离**，而不是 improvise：
- 无同设备物性/热曲线依据
- `TascMsg` 含未解决的输入错误或操作失败
- 物性曲线不覆盖操作包络
- 出口温度/相态/duty/压力非物理
- EDR 绑定未经授权改了受保护工艺目标
- Required Input 或最终 Run Status 非零
- 合格的 HeatX 未被覆盖

## 7. 迁移规则（Transfer Rule，防数值污染）

方法、字段含义、失败特征、证据顺序、晋升门可迁移；**另一台换热器的流股、duty、面积、几何、材料、污垢、压降、方法选择、串并联安排一律不得迁移**（除非有同设备证据）。

## 8. 本 skill 的方法论层次

- **本 skill（EDR-skill）** 聚焦**单台换热器从零设计/评级/交付**，是完整的设备级技能。
- 方法论分两层：本文档是**速览**，`edr-rating-methodology.md` 是**完整规范**（三权威 + HeatX 状态机 + 8 步工作流 + 工程验收门 + 停止/迁移规则 + 返回契约）。
