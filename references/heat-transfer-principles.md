# 传热与换热器化工原理（热力设计的方法论底座）

> 本文档是 EDR-skill 的化工原理知识底座，把换热器热力设计的"原理层"固化下来。
> 核心思想一句话：**热量、温位、热阻网络三者必须同时闭合；换热量闭合 ≠ 温度曲线无交叉、压降可接受、设备可操作。**

---

## 1. 传热机理与设备层面的统一要求

导热、对流、辐射及相变传热机理各不相同，但在换热器设备层面必须同时满足：

1. **热量守恒**：冷侧吸热 = 热侧放热（含显热 + 潜热 + 反应热）；
2. **可用温差**：全程最小温差（热源温位 vs 冷源温位）必须 > 0，否则温度曲线交叉；
3. **各段热阻**：膜传热 + 污垢 + 壁面 + 相变 + 分布 层层叠加。

总传热能力受**控制热阻（最大的那一项）**、有效面积、流动状态、污垢、壁面、相变与流体分布共同约束。

> 工程铁律：**总传热系数 U 不是脱离物系、流型和设备结构的通用常数。** 手册上的"水-水 1000~2500 W/m²·K"只是量级 sanity check，不能当作 EDR 结果。

## 2. 换热器设计的方法链（L1 方法族）

```
热量衡算 → 温度/相态曲线 → 导热/膜/污垢/壁面热阻
→ 局部或平均推动力（LMTD/ε-NTU） → 面积 → 流动与压降
→ 设计/校核 → 结垢与变工况
```

**关键原则**：
- 无量纲关联式（Nu、f、j 因子）必须绑定**几何、流型、物性取值温度和适用区间**。
- **设计计算**（已知负荷求面积）与**校核计算**（已知面积求负荷/出口）的已知量和目标不同，不能混用。EDR 里 `Design` 与 `Rating` 两种模式正是对应这两种。

## 5. 工程判断要点

- **先确认热源温位和全程最小温差，再谈换热面积。** 温差不足，面积再大也没用。
- **强化传热要算总账**：比较新增压降、泵/压缩功、污垢、振动、材料和维护负担，不能只看 U 提升。
- **热回收需时间匹配**：旁路/控制、启动热源、失去热源时的备用路径都要有。
- **设计 vs 校核不混用**：已知量与目标不同，走错模式 = 全错。

## 6. 禁转清单（Transfer Rule 的物性侧）

总传热系数、污垢系数、关联式常量/指数、图表值、温差修正、例题几何和设备形式，都必须**按当前物系、结构、标准及软件/厂家证据重新确定**，不得从教材/其他项目直接照搬。
